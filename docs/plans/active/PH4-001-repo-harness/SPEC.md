# PH4-001 Repository Harness

## Objective
Make the repository safe and legible for a fresh coding agent and create the isolated v2 kernel foundation without modifying v1 behavior.

## Scope
- root agent instructions;
- architecture/decision docs;
- task/handoff templates;
- v2 Rust crate;
- typed foundational values;
- command harness skeleton;
- workspace integration.

## Non-goals
- markets;
- ledgers;
- shipments;
- ScenarioPack runtime loading;
- UI changes;
- v1 refactors.
